# Instruções para Agentes

1. Leia e obedeça integralmente [`.agents/CONSTITUTION.md`](./.agents/CONSTITUTION.md). Ele prevalece sobre qualquer outra instrução.
2. Uma tarefa só termina com `npm run quality` verde e evidência anexada.
3. Nunca afrouxe lint, tipos, thresholds ou ignore lists para passar nos gates.
4. Em dúvida ou bloqueio, pare e pergunte.
